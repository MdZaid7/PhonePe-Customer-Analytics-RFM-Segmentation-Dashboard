# PhonePe Customer Analytics | SQL, Python & Power BI

## Project Overview

This project focuses on analyzing customer and transaction data from a PhonePe-like digital payment platform. The goal was to understand customer behavior, identify valuable customer segments using RFM Analysis, and build interactive dashboards that provide meaningful business insights.

The complete workflow includes data cleaning in SQL, customer segmentation using Python (Pandas), and dashboard development in Power BI.

---

## Dataset Summary

- Total Customers: **107,658**
- Total Transactions: **300,000**
- Total Revenue: **₹347.43 Cr**
- Analysis Period: **2023 - 2025**

---

## Project Workflow

### 1. SQL

- Imported and explored the dataset
- Cleaned and validated the data
- Removed inconsistencies
- Performed exploratory SQL analysis
- Prepared data for Python and Power BI

### 2. Python

Performed RFM (Recency, Frequency, Monetary) analysis using Pandas.

Created customer segments such as:

- High Value
- Loyal
- Regular
- Needs Attention
- Lost

The final segmented dataset was exported for Power BI.

### 3. Power BI

Designed three interactive dashboards:

### Customer Insight

- Customer overview
- Revenue by age group
- Top spending customers
- Customer growth trend

### Transaction Insight

- Revenue analysis
- Transaction trends
- Success rate
- Failed transaction reasons
- Service-wise transaction analysis

### Customer Segmentation

- RFM customer segmentation
- Revenue by customer segment
- Transaction frequency
- Average recency
- Customer distribution
- Recency vs Monetary analysis

---

## Key Business Insights

- High Value customers generated the highest revenue despite representing a smaller customer group.
- Loyal customers completed the highest number of transactions.
- Lost customers showed the highest recency, indicating inactivity.
- Money Transfer contributed significantly to total revenue.
- Most transactions were completed successfully, reflecting strong platform performance.
